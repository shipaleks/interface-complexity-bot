# UI Visual Analyzer Telegram Bot

Telegram-бот для автоматического анализа пользовательских интерфейсов (UI). Бот принимает скриншоты, проводит анализ с использованием GPT-4.1 и Gemini, и предоставляет подробный отчет о проблемах интерфейса и рекомендации по улучшению.

## Возможности

- **Когнитивный анализ интерфейса**: выявление проблем UI/UX, оценка сложности, определение проблемных зон.
- **Генерация визуальной тепловой карты**: визуальное представление проблемных зон интерфейса.
- **PDF-отчет**: подробный отчет с анализом каждой категории проблем.
- **Стратегическая интерпретация**: глубокий анализ интерфейса как когнитивной экосистемы.
- **Стратегические рекомендации**: практические рекомендации по улучшению интерфейса.

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository_url>
cd visual_analyzer
```

2. Установите необходимые зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` со следующими переменными окружения:
```
TELEGRAM_BOT_TOKEN=ваш_токен_telegram_бота
OPENAI_API_KEY=ваш_ключ_openai_api
GEMINI_API_KEY=ваш_ключ_gemini_api
```

## Запуск бота

```bash
python telegram_bot.py
```

## Файлы проекта

- `telegram_bot.py` - основной файл Telegram-бота
- `analysis_pipeline.py` - модуль оркестрации всего процесса анализа
- `generate_report_v2.py` - скрипт для анализа скриншота с помощью GPT-4.1
- `get_gemini_recommendations.py` - скрипт для получения интерпретации и рекомендаций от Gemini
- `gemini_interpretation_prompt.md` - шаблон запроса для стратегической интерпретации
- `gemini_recommendations_only_prompt.md` - шаблон запроса для стратегических рекомендаций

## Использование

1. Найдите бота в Telegram и отправьте команду `/start`
2. Отправьте скриншот интерфейса для анализа
3. Опционально опишите, что изображено на скриншоте и какие пользовательские сценарии связаны с этим экраном
4. Дождитесь результатов анализа
5. Получите PDF-отчет, тепловую карту, стратегическую интерпретацию и рекомендации

## Требования

- Python 3.8+
- OpenAI API ключ (для GPT-4.1)
- Google Gemini API ключ
- Telegram Bot API ключ

## Зависимости

- aiogram - для работы с Telegram Bot API
- openai - для работы с OpenAI API
- google-generativeai - для работы с Gemini API
- python-dotenv - для загрузки переменных окружения
- Pillow - для обработки изображений
- matplotlib - для генерации тепловых карт
